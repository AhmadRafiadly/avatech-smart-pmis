# Demo Scenario - AIS Universitas

## Purpose
Demo AIS Universitas dibuat untuk menyiapkan skenario cerita end-to-end yang matang untuk sidang akhir.

## Demo Project
Project: Sistem Informasi Akademik Universitas
Client: Universitas Nusantara
Method Context: RUP
Project Type: Web-based Academic Information System

## Main Story
Client membutuhkan sistem akademik untuk mengelola data mahasiswa, dosen, KRS, KHS, jadwal kuliah, nilai, dan laporan akademik.

Smart-PMIS digunakan untuk mengelola proses dari requirement gathering sampai QC/test case.

## Demo Flow
1. Login sebagai CEO/PM.
2. Buka Executive Monitor.
3. Buka project AIS Universitas.
4. Masuk Project Detail.
5. Buka Requirement Intake.
6. Upload atau input PRD/proses berjalan.
7. Isi ringkasan kebutuhan.
8. Buka MoM.
9. Input notulensi gathering.
10. Jalankan AI MoM Fixer.
11. Review dan apply hasil AI.
12. Jalankan AI WBS Generator dengan konteks requirement.
13. Review dan apply WBS.
14. Tampilkan modul dan task.
15. Tampilkan Quick Assign / Team Assignment.
16. Tampilkan Kanban Workspace.
17. Tampilkan dependency/Gantt-lite jika sudah tersedia.
18. Buka QC/Test Case.
19. Jalankan AI Test Case Generator.
20. Review dan apply test case.
21. Export PDF WBS/Test Case.
22. Tampilkan Audit Trail.
23. Tampilkan AI Monitor / fallback evidence.
24. Tampilkan Testing Evidence.
25. Tampilkan Formula Reference.

## Suggested Modules
- Authentication & RBAC
- Data Mahasiswa

- KRS
- KHS
- Jadwal Kuliah
- Nilai

- Export Laporan

## Sidang Message
Demo ini menunjukkan bahwa Smart-PMIS tidak hanya menyimpan data proyek, tetapi menghubungkan dokumen kebutuhan, MoM, WBS, task, Kanban, QC, AI assistance, audit trail, dan evidence pengujian dalam satu alur kerja.
