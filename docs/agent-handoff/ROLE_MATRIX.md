# Role Matrix

## CEO/PM
Current focus role.

Access:
- Executive Monitor: full view
- Project Master: full access in UI
- Project Detail: read-only, view/export only
- Client Directory: full access
- Team Management: full access
- Audit Trail: full access
- Settings: full access

Rules:
- CEO/PM must not edit Project Detail operational data directly.
- CEO/PM can manage clients, team, and settings.
- CEO/PM should see business overview, workload, health, alerts, and audit history.
